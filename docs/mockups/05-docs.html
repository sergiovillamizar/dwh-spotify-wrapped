Auth

Endpoints de autenticación OAuth 2.0 con Spotify. Manejan el flujo completo de Authorization Code + PKCE.

GET /v1/auth/login

Inicia el flujo OAuth con Spotify. Redirige al usuario a la página de autorización de Spotify.

Query Parameters

redirect_uristringURL de retorno tras autorización

Response

{ "auth_url": "https://accounts.spotify.com/authorize?..." }
GET /v1/auth/callback

Callback OAuth. Recibe el código de autorización y retorna un JWT firmado.

Query Parameters

codestringCódigo de autorización de Spotify

Response

{ "token": "eyJhbGciOiJIUzI1NiIs..." }
GET /v1/profile/me

Obtiene el perfil del usuario autenticado desde el Data Warehouse. Requiere JWT.

Headers

AuthorizationstringBearer token JWT

Response

{ "display_name": "Juan Pérez", "email": "juan@email.com", "product": "premium" }
